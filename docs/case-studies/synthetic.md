# Synthetic enterprise scenarios

No real customers or production outcomes. Employee stakeholders need discoverable leave policies; sales needs SKU evidence; engineers need credential-rotation instructions. The local demo filters a fixed synthetic corpus by simulated role before lexical or embedding retrieval, then verifies citations against the authorized corpus. Acceptance: expected top source for three scenarios, restricted compensation record absent for employee, unknown roles rejected, citations match allowed corpus. Run npm test and the local dashboard. Real deployment requires authenticated identity, tenant isolation, authoritative document ACLs and revocation, independent security review, operational monitoring and feedback. The role selector is not an authentication boundary.
